# ADR 0001 — Use Rust as the core language

**Date:** 2026-07-01  **Status:** Accepted

## Decision

All Atlas crates and the CLI are written in Rust.

## Why

Atlas is a long-running service that will ingest large git histories. Rust gives:
- Memory safety without GC pauses during sustained ingestion
- `serde` for zero-boilerplate serialization of all IR types
- `clap` derive macros for a typed CLI with no reflection
- `rusqlite` with bundled SQLite — single static binary, zero system deps
- `tracing` for structured diagnostics from day one

## Alternatives rejected

- **Go**: Good concurrency, simpler. Weaker type system for modeling the IR graph.
- **Python**: Fast to prototype. Runtime errors at scale; too slow for large repo ingestion.
- **TypeScript**: Excellent CLI ecosystem. V8 overhead unacceptable for a background daemon.
